# Figure source data

The complete processed data directory is provided in the [v1.0.0 research package](https://github.com/DongXuEco/perceptatlas/releases/download/v1.0.0/perceptatlas-research-v1.0.0.zip).

Download and extract that archive to obtain `data/` alongside `code/`. It contains the unchanged numerical source tables and shared inputs. Files in this folder are not downloaded automatically by the analysis scripts.

GitHub's automatically generated **Source code** ZIP contains the repository files only; use the explicitly attached **perceptatlas-research-v1.0.0.zip** asset for the data-inclusive package.

See [data_dictionary.csv](../data_dictionary.csv), [figure_inputs.csv](../figure_inputs.csv), [figure_index.csv](../figure_index.csv) and [LICENSE_DATA.md](../LICENSE_DATA.md).
