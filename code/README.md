# Analysis and figure code

- [`figures/`](figures): actual plotting implementations named by final manuscript figure number.
- [`analysis/`](analysis): processing, statistics, validation and environmental-association models.
- [`_support/`](_support): shared plotting functions and package utilities.
- [`requirements.txt`](requirements.txt): recorded Python dependencies.
- [`run_analysis.py`](run_analysis.py): list or run analysis tasks.

Download the [data-inclusive release](https://github.com/DongXuEco/perceptatlas/releases/tag/v1.0.0) before running. See [reproduction instructions](../docs/REPRODUCIBILITY.md) and the original [code notes](README.txt).
