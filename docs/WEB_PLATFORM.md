# The interactive PerceptAtlas

[Open the live platform](https://perceptatlas.com/)

![PerceptAtlas home](assets/platform-home.png)

## Maps and location evidence

Explore six predicted perceptual dimensions, city ELI, zoom-dependent place labels and reference cartography. Location queries inspect the original raster pixel; low-zoom overview imagery is a display approximation. Visual glow is a display effect and does not represent extra data coverage. The source grid uses EPSG:4326 with 0.00135° angular spacing, rather than a uniform metric resolution.

![Map exploration](assets/platform-map.png)

## Synchronized layer comparison

In Map → Dual globe, compare perceptual layers with a shared camera. Matching views support visual comparisons while the underlying source rasters remain separate.

![Dual-globe comparison](assets/platform-dual-globe.png)

## City evidence and analysis

Browse the city directory, compare cities and inspect distributions, North–South differences, relationships and core–expansion contrasts. Numerical evidence can be exported from the interface. Website statistics reflect the selected cohort and need not equal every fixed manuscript statistic.

![City analysis workbench](assets/platform-analysis.png)

The platform is a separately hosted application. This research repository provides its public entry point and screenshots, alongside the paper’s numerical evidence and code. It does not deploy the raster service through GitHub Pages or distribute the underlying web infrastructure.
